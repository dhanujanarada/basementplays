# Dear Daughter textures

Drop the optional production textures here. The design works without them, using
CSS gradients and scalloped edges as fallbacks.

| File | Used for |
| --- | --- |
| `damask.png` | Hero wallpaper behind the title and partner strip |
| `torn-edge.png` | Torn-paper top edge of the cream show-dates section |

Use transparent PNGs (or WebP files renamed to `.png`). The hero texture is tiled at
about 360px wide; the torn edge repeats horizontally at the height of the section
edge. Keep both reasonably small so the production page stays fast.

Partner logos are not stored here. Upload them per partner in Backstage under
**Productions → Dear Daughter → Partners → logo**.
